本项目是一个完整的点餐系统，包含用户端小程序和管理后台：
- **用户端**：uniapp 跨平台小程序，提供点餐、购物车、个人中心等功能
- **管理端**：SpringBoot 后台，提供商品管理、订单管理、用户管理等接口
- **数据库**：MySQL ，存储商品、用户、订单等数据

### 前端（uniapp）
- **框架**：uniapp (Vue 3)
- **状态管理**：Pinia
- **UI组件**：uni-ui
- **网络请求**：uni.request
- **跨平台**：支持微信小程序、H5、App

### 后端（SpringBoot）
- **框架**：Spring Boot
- **持久层**：Spring Data JPA
- **数据库**：MySQL 
- **接口风格**：RESTful API
